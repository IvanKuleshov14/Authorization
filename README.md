# Модуль двухфакторной аутентификации
Реализация библиотеки авторизации с поддержкой двухэтапной беспарольной аутентификации через Email и Telegram на основе JWT-токенов

## Стек технологий
* **Backend:** ASP.NET 10 (Web API, Архитектура с разделением на слои)
* **Database:** PostgreSQL + Entity Framework Core
* **Containerization:** Docker & Docker Compose
* **Testing / Mail Server:** Mailpit (локальный SMTP-сервер для перехвата Email)

## Архитектура и функции

Система реализует современную концепцию, избавляющую пользователя от необходимости запоминать статические пароли

### Сценарий работы модуля:
1. **Этап 1 (Идентификация):** Пользователь передает свой `Identity` (Email или TelegramId) и указывает провайдера (Email или Telegram). Система проверяет существование пользователя, либо создает нового и генерирует временный шестизначный код
2. **Этап 2 (Верификация):** Пользователь вводит полученный код. Система валидирует его и генерирует сессионный **JWT-токен**

### Инфраструктура в Docker Compose:
* `authorizationapi` — основное приложение ASP.NET Core
* `auth_postgres` — база данных PostgreSQL
* `auth_mailpit` — локальная SMTP-заглушка. Перехватывает письма из C# кода, исключая необходимость настройки реальных серверов при проверке

## Руководство программиста: локальное развертывание

### 1. Подготовка окружения
В корне проекта создайте файл `.env` и укажите ваши данные: пароль для базы данных (по умолчанию для dev-окружения: mypassword) и токен telegram-бота:

```env
DB_PASSWORD=mypassword
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
```
* ! Убедитесь, что файл назван строго `.env` и не содержит расширения (например `.txt`)
* Для получения токена telegram-bota создайте собственного бота через @BotFather: `/start` => `/newbot` => дальнейшие инструкции бота
* ! Не забудьте зайти в чат именно созданного Вами бота и выполнить команду `/start`, иначе код приходить не будет

### 2. Запуск всей инфраструктуры
Проект полностью контейнеризирован. Варианты сборки и запуска:
1. Выполните команду в терминале корневой папки: `docker compose up -d --build`
2. Откройте решение в Visual Studio, выберите профиль запуска Docker Compose и запустите проект

## Инструкция по тестированию
Перейдите в интерфейс Swagger (http://localhost:5000/swagger)
### Шаг 1. Запрос одноразового кода доступа
**Запрос:** `POST /Auth/send-code`
```json
{
  "identity": "guest@example.com",
  "provider": "Email" 
}
```
или
```json
{
  "identity": "799220840",
  "provider": "Telegram" 
}
```
Используйте бота @userinfobot, чтобы узнать TelegramId пользователя

### Шаг 2. Верификация кода и получение JWT-токена
Если выбран провайдер Email — перейдите в интерфейс Mailpit (http://localhost:8025)

**Запрос:** `POST /Auth/verify-code`
```json
{
  "identity": "guest@example.com",
  "code": "123456"
}
```
**Успешный ответ (200 OK):**
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VySWQiOi..."
}
```
